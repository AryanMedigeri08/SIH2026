🛡️ Anticipated Jury Q&A for Slide 2

Q1: "Census 2011 is 15 years old. How can banks trust your market demand estimates?"
Defense: "We never use raw 2011 figures directly. We apply official state-level Compound Annual Growth Rates (CAGR) from RBI/MoSPI to project populations forward to 2026, cross-referenced with live district MSME registration density and CPI inflation indices."
Q2: "How will this platform make money or sustain itself financially?"
Defense: "We use a B2B SaaS model: feasibility checks remain free for rural entrepreneurs, while commercial banks (SBI, PNB, RRBs) pay nominal API fees for pre-underwritten, audit-ready loan leads with pre-calculated DSCR, reducing their credit appraisal cost by over 80%."
Q3: "What if an external API like Data.gov.in or Groq goes down?"
Defense: "Our platform incorporates a zero-crash offline resilience mode. Core banking math and XGBoost inference run locally in Python without external API dependency, falling back to deterministic template narratives if LLMs are unreachable."
